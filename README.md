# Tafu — maternal referral coordination

A concept for helping community health workers and civil society organizations coordinate maternal referrals with limited staff and resources.

- [Concept assessment, recommended stack, public APIs, and prototype scope](docs/prototype-assessment.md)
- [Original supplied HTML concept](reference/tafu-demo.html)

The HTML is preserved unchanged as reference. Its records, statistics, predictions, and intervention narratives are synthetic concept content, not verified program results. Most action controls are illustrative. There is no implemented backend or active patient workflow yet.

Recommended first build: React + TypeScript + Vite, local synthetic data in IndexedDB, a working referral-to-outcome journey, and limited public-data context. See the assessment for the phased implementation and verification plan.
